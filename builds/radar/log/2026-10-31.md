These go to houses I'll never see, so first boot changed the most.

- **No baked-in Wi-Fi:** gift builds boot to a setup hotspot. Credentials live only in a gitignored dev file.
- **No baked-in location:** nothing is fetched until a location is saved from the web page.
- **Power cuts:** if the saved network won't connect, the hotspot times out after 3 minutes and the radar goes back to retrying it.
- **Device page:** redesigned from scratch. Radar, flight strips, plane details with routes and photos, a first-run "Where is your radar?" step, and settings for looks, range, units, updates, Wi-Fi and factory reset.

A second S3 Super Mini boot-looped on its first flash. Its GD flash returned garbage on quad reads under the default QIO bootloader. Builds now use DIO.

> **Trap:** OTA never rewrites the bootloader, so the flash mode has to be right on the first USB flash.
