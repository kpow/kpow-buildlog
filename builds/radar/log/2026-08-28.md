The radar had started coming up empty. Grid, sweep, no planes. The fetch succeeded, the heap was fine, and nothing logged an error for a full day.

The endpoint sits behind Cloudflare and had started answering with `Transfer-Encoding: chunked`. `getStreamPtr()` hands back the raw socket and never de-chunks, so hex chunk-size lines were landing in the middle of the JSON. With a filter in place that parses as *Ok* against an empty document, so the fetch published zero aircraft, returned true, and never backed off.

> **Trap:** a parser that succeeds on garbage is worse than one that crashes on it. The empty-`ac` case now logs instead of publishing silence.

Fixed with a small stream wrapper that de-chunks when `getSize()` reports -1 and passes identity bodies straight through, so the body still never gets held whole. `useHTTP10(true)` also kills chunking, but then the body is close-delimited and WiFiClientSecure truncates it, which trades a silent bug for a noisy one. Verified on the S3: ten clean fetches in a row, idle heap 105 KB, worst min-free 26 KB.
