Portability pass. Every board's `platformio.ini` now pins the pioarduino platform by URL, so a build on a new machine produces the same firmware as the old one instead of whatever the toolchain drifted to.

The 12×8 matrix satellite moved to a dual-core ESP32-S3 SuperMini for the better radio, and the 16×16 got a baked Pac-Chase animation as its own source.
