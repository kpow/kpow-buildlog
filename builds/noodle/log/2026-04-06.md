Split the firmware into four FreeRTOS tasks across both cores, with the network moved to core 0 so the radio and the LED render stop fighting over the same core.

Every piece of hardware gets exactly one owner task. That rule has survived every rebuild since, and it's the reason a WiFi hiccup doesn't stutter an animation.
