Wrote my first pattern from scratch for the Patternflow bank: a Mondrian grid that keeps rearranging itself. It builds the layout by splitting the canvas in two and then splitting the pieces, which is how his paintings are put together, so it's always a valid composition. Built a small browser harness to work on it in JavaScript first, then hand-ported it to C++ for the hub75. The two versions match pixel for pixel.
