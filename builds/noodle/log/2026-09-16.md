Wrote my first pattern from scratch for the Patternflow bank: a Mondrian grid that keeps rearranging itself.

It builds a layout by splitting the canvas in two, then splitting the pieces, which is roughly how the paintings are put together. Whatever it lands on is a valid composition rather than a scatter of rectangles.

Worked it out in JavaScript first, in a small browser harness, then hand-ported it to C++ for the hub75. The two versions match pixel for pixel, which is the only reason I trust the port.
