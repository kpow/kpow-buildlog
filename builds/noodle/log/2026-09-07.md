Recomposed the whole UI for a landscape 320×240 mount, because the ribbon was blocking the view in portrait: one-row header, framed menus, Live Control and Chladni both re-laid out. Landscape puts text beside its neighbours instead of into dead space, so every variable-length name now goes through a fitter before it's drawn.

The Patternflow bank landed the same week: JS shader-style patterns hand-ported to C++, running on all three boards. The red Qwiic button got demoted from "previous pattern" to a palette dice, because I never once used it as a back button. The dial already has back.
