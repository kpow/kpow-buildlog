Dropped WiFi association altogether. The Console brings the radio up for ESP-NOW and never joins an access point, which means no router, no DHCP lease, and nothing to go stale between sessions.

Started the screen-share path as well, browser to ingest to matrix, with a LittleFS clip store behind it, so I can push real captured pixels at the 16×16 instead of only generated effects.
