Built out the pixel satellites: a 1×30 bar, an 8×8 icon panel, a 16×16 matrix. Each one is its own board rendering locally, fed by a shared wire format (v5) that carries effect state rather than pixels.

That distinction matters. Sending state means a satellite keeps animating at its own frame rate even when a packet goes missing.
