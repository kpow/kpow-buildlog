Added an attract mode: on power-up it plays a self-animating tower demo behind the start screen. At boot the firmware reads the button and treats whatever state it sees as "not pressed," so it auto-detects NO *or* NC wiring and I don't have to track which switch was soldered in. The attract loop replays the tower animation after two title scrolls, and the game-over screen falls back to attract mode after two scroll passes, so it always returns to the start state.
