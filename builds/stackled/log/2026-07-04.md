Scaffolded the project in PlatformIO, ran a bring-up test build, then wrote the full game firmware: engine, level progression, and scoring. The core is a non-blocking `millis()` state machine running pure bitmask stack logic. Each row is a `uint8_t`. To land a piece, AND a candidate row with the row below to keep only the overlapping pixels; popcount gives the resulting width, count-trailing-zeros gives the left edge. No pixel arrays — the whole field is bits. Renamed the project to STACKLED and removed a duplicate copy of the build guide. Wrote the build guide out in full, including 5-band resistor bodies drawn with the correct color codes so the BOM reads directly off the page. High score is stored in NVS, so it survives a power cycle.
