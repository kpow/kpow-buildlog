Full bring-up on the 8×32: flipped both display axes so the tower grows upward, fixed the NC button contact, and ran a speaker siren test. Added a lives system — four complete misses per game, with a pip flashed on each miss. Bumped the matrix intensity from 6 to 10 so it reads in a lit room. Handed out the first three rows as free "grace rows" so a fresh player doesn't lose on the first move. Started swallowing stale button presses across state transitions: a leftover press on the game-over screen was skipping the next screen.
