I use vizMac from another machine now, so the controller became a remote for the Mac it runs on. Pressing keys 3 and 4 together opens a fifth mode, Mac. It's also a card in the mode picker.

- **Volume:** the knob, through AppleScript. The Mac reports its output device by name over Core Audio.
- **Play/pause, next, previous, brightness:** posted as the same system-defined key events the F-row sends, so they reach any app, browsers included. That needs Accessibility permission.
- **The F-row:** hold KO and a row of six keys appears, F1 F2 F7 F8 F9 F10, opening on Mute.

> **Trap:** the first try ran AppleScript in-process with NSAppleScript on a worker thread. vizMac.app died at launch with a SIGTRAP. It runs osascript in a subprocess now.

Keys 3 and 4 wait 80 ms for each other before a lone press counts, so the chord never also switches modes.
