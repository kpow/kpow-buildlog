The controller is going into its case, so it needed updates without USB.

- **OTA:** `pio run -e ota -t upload` flashes it over Wi-Fi in about 30 seconds. An Updating screen shows on the display, and the LED panels become a progress bar.
- **From the web UI:** a Controller card lists each controller's firmware and offers the build bundled with vizKeys when it's newer. The controller picks up the request on its next poll, downloads the image, checks its MD5, switches app slots and restarts.

A failed update leaves the running firmware alone. The web path was tested with a bad checksum first, then a real update.
