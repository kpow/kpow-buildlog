The Noodle 2K Console has a palette it generates rather than stores, rolling new colours and morphing into them. vizMac now has the same one: a single runtime slot, id 255, sitting beside the 23 curated palettes.

vizMac plays the Console's role here. It owns the roll and the 2.5 s smoothstep morph, and every surface renders whatever colours it is handed: the keyboard, the web UI swatch, the menu bar and the controller. A dice action mirrors the Console's red button, a coin flip between jumping to a different curated palette and rolling a new Live one. The sync packet grew an optional tail carrying the 16 colours, which older controllers read past and ignore.

> **Trap:** the controller's ArduinoJson catalog filter only passed name and colors, so every palette's id fell back to its position in the list. Live arrived as 23 instead of 255. Picking it in the web UI left the controller showing the first palette, and picking it on the controller sent an id vizMac rejects. The fix was one line in the filter.
