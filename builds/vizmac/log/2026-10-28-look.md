A design agent pass refreshed both UIs. Concept A "Dock" and the Slackey font stayed as the baseline.

- **Controller:** back pills tinted in each mode's colour, a dock bar under the hints, cards without outlines, and a coloured header band on the mode picker cards.
- **Web UI:** Slackey for the headings, one colour per mode, and a Mac card with a volume gauge, mute and the same six F-row keys.

The firmware went into the vizMac bundle the same day, so the first controller can update from the web UI.
