vizMac finds every WLED light with Bonjour: 13 on the home network. The web UI's new Lights card picks which ones the controller lists and in what order, with an Open link to each light's own page. The controller keeps the list and talks to the lights directly, so it works with the Mac asleep.

The controller now sleeps when the Mac's screens sleep or lock, and wakes with it.

With all that it stopped being a keyboard app. vizKeys is now vizMac: the repo, the app, the Bonjour name and the controller. The controller learned the new name first and kept looking for the old one, so it never lost the Mac mid-rename.
