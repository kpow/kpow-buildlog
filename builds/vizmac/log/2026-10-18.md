Built a second controller, same guts as the first, in a white shell with four key switches down the right side. They sit in a printed strip beside the screen, wired by hand: one ground link across all four, one signal wire each into a 5-pin JST.

Each key opens one mode: Keys, Now Playing, Clock, WLED. They fire on the press rather than the release, because a dedicated key has nothing else it could mean. A key works from anywhere in the UI and from sleep. Pressing the mode you are already in drops back to that mode's main page, so a key is also a way out of any screen.

> **Note:** my own wiring notes said to avoid GP3 because it's a strapping pin. The JTAG select is only read once that efuse is burned, so GP3 reads like any other input. The four keys are on GP6, GP5, GP4 and GP3.

The pins sit on the internal pull-up, so the first controller's bare pins float high and never fire. One firmware runs on both.
