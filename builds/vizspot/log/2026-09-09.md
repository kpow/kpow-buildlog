Ambient got a memory. It keeps 20 tracks with their covers, seeded from Spotify's recently-played at boot, and fades one back in with how long ago you played it. NTP for the clock, PSRAM for the API bodies.

The rest of the day:

- **Kaleidoscope:** a post-filter over any effect, NoodleLab's fold modes, live controls on the page
- **Puzzle:** 16 px tiles on the 64×64, proportional borders, faster eased slides
- **Snakes:** rendered at 32×32 and upscaled, so the bodies are 2 px and you can see them
- **Control page:** neo-brutalist restyle, collapsible cards, transport buttons

Then a stuck-on-song bug. After a token expired the display never moved on, because the refresh was going out while the API session was still open.

> **Lesson:** there is room for exactly one TLS context. The API, the token endpoint and the art CDN take turns, and whoever wants it drops the other's keep-alive first.
