Put Spotify search on the control page, with the browser calling Spotify directly through a token endpoint so the board carries none of it.

Most of the work was in what Spotify does when you ask it to play something:

- a limit above 10 comes back 400, so the search asks for 10
- playback needs an explicit device id, and a stale one has to be retried
- a browser player accepts a queue and then refuses to play, so the picker prefers real Spotify apps and warns you when you've chosen one

The page got per-card Save buttons and speed sliders for the visualizer and ambient while I was in there. Then the docs, all four: README, user guide, hardware guide, web API reference.
