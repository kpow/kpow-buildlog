Put Spotify search on the control page, with the browser calling Spotify directly through a token endpoint so the board carries none of it. That turned into a device picker, an explicit device id, a retry on a stale device and plain-language errors — a browser player will not take playback, which the page now warns about. Reorganized the page into cards with their own Save buttons, added speed sliders, and wrote the README, user guide, hardware guide and API reference.
