Phases 0 through 5, one sitting:

- **Panel:** HUB75 DMA driver, boot test pattern
- **Settings and web:** NVS storage, captive-portal WiFi manager, JSON API
- **Spotify:** a PKCE helper script, then the on-device client with refresh, polling and backoff
- **Art:** cover pulled over HTTPS into PSRAM, decoded with JPEGDEC, box-resampled to 64×64, crossfaded on track change
- **Sound:** ES7210 mics, FFT and beat detection running on the board, the effect catalog behind them

The mode state machine came last and tied the scenes together.
