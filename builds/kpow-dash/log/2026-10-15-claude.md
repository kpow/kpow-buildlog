Ask mode first: Opus 5.5 through the Agent SDK tool runner, streamed to the panel over
SSE, with read-only tools covering every tile's snapshot plus the kpow MCP over stdio.
Tokens are spent on one route, `POST /api/chat`, and the panel prints the day's total
so I can see what a question cost.

Change mode came the same evening. Preview edits a `dash/<slug>` branch inside its own
git worktree and serves it on :4042; keep fast-forwards main, undo deletes the branch.
Apply now goes straight onto main and dev hot-reloads it, with `git revert` behind the
undo. Claude gets file edits in that worktree and one command, `npx tsc --noEmit`. The
typecheck gates preview, keep and apply, and a failure undoes the change and says why.

Seven commits that night were written by the dash about itself. The first added a trash
button to each email row. By the last one I was asking for layout changes the way I
would ask a person: more height on the today box, ten emails per account, six project
cards per row.
