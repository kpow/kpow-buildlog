Added leaderboards with three scopes: a global board across all players, a per-tour board
scoped to the current run, and a single-show board for one show's predictions. Each board
ranks the top predictors for its scope, and each board's view buttons link straight to the
relevant scorecards, so you can go from a ranked name to that player's scored prediction in
one click. This is the piece that turns scored predictions into an ongoing competition
between shows.
