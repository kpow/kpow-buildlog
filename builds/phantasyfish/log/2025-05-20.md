Added an admin interface for editing setlist details by hand, because the official data is sometimes wrong and sometimes just late, and every scoring run depends on it.

A mangled setlist can be corrected, or a generated one refined, before it scores. Malformed source data fails with an error I can read instead of a stack trace.
