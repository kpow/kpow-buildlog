Added an admin interface for editing setlist details directly, because the official data
isn't always right, or isn't posted yet, and the whole scoring run depends on it. Now a
mangled setlist can be corrected or an auto-generated one refined before it scores, with
better error handling for when the source data is malformed. The scoring run is only as
good as the setlist it's fed.
