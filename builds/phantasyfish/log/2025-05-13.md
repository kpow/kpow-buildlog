Built the back office: admin pages to manage files, songs, users, and WookBot setlists
from one place. Running a live game means constantly touching data — fixing a song entry,
checking an account, curating a generated setlist — and doing that directly against the
database was getting slow. The console replaced a batch of one-off scripts with actual
screens.
