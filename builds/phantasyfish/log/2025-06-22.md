Built a tour manager and started tracking per-tour song counts — how many times each song
has been played on the current run. Phish is organized by tour, so almost every view worth
having — leaderboards, research, Wrapped stats — depends on knowing which shows belong to
which tour. Getting that structure right unlocked a lot of the features that came after.
