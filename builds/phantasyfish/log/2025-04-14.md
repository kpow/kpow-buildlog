Built the scorecard: a two-column set 1 / set 2 layout with a breakdown showing which
songs contributed to your points. Wired in real 2024 show data to score predictions
against, so a finished prediction could be scored for the first time. The score button
stays hidden until a show is officially scored, so players don't see a wall of zeros
before the band has played.
