First commit. The build-a-setlist UI is on screen: drop songs into slots, reorder them,
and add sets as you go. Seeded the song database by pulling from several phish.net
endpoints, then cached the result to a local JSON file so the game doesn't hit the API on
every load. Prediction saving landed the same day, so the core loop — build a setlist,
save it as a prediction — was working end to end from day one.
