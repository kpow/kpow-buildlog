First commit, and the core loop worked the same day: build a setlist, save it as a prediction.

The build-a-setlist UI went up first. Drop songs into slots, reorder them, add sets as you go. Then the song database, seeded out of several phish.net endpoints and cached to a local JSON file so the game isn't hammering their API on every page load.
