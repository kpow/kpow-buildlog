Built resilience against the phish.net data source going down mid-show, the worst failure
mode for a live-scoring game. Added a local phish.net mirror with background sync, a
database fallback for show endpoints when the API is blocked, and the ability to score
straight from a hand-entered live setlist when the network won't cooperate. A bad night on
someone else's server no longer takes the game down with it.
