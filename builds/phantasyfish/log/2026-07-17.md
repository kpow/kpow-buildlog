Hardened the game against phish.net going down mid-show, which is the worst possible failure for live scoring: the band plays on, and the game goes blind.

Three layers, in order of desperation:

1. a local phish.net mirror with background sync
2. a database fallback for show endpoints when the API is blocked
3. scoring straight from a hand-entered setlist when the network won't cooperate at all

A bad night on someone else's server doesn't take the game down with it any more.
