Added an admin feature to import upcoming shows straight into a tour, so setting up a new
season is a few clicks instead of hand-entering a schedule. This came after splitting the
admin routes out of one giant file into modular pieces — the console had grown enough that
the routing needed to be maintainable, not just working. The refactor keeps the cost of
adding the next feature down.
