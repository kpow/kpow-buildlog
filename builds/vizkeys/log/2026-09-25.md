Wired the controller from the plan: a Waveshare ESP32-S3-Tiny, the same 2.4" ST7789 as the Noodle Console with an EC11 encoder and KO button on its board, and two 8x8 WS2812 panels chained on one data pin as a 16x8 preview. Only the S3-Tiny's edge through-holes get used, so the display sits on one edge in header order with no crossed wires.

Bring-up firmware checked each part on its own:

- **Board:** 4 MB flash and 2 MB PSRAM found.
- **LEDs:** solid colors, a dot walking 0 to 127, corner markers, rainbow. One panel had a dead pixel at #10, so I swapped it. All 128 work.
- **Screen:** full 320x240 frame, colors in order.
- **Knob and buttons:** one encoder count per click, push and KO both register.

The case is printing alongside. The white prints are test pieces for finalizing the fit.

> **Trap:** this ST7789 panel is BGR. With the default RGB order, red showed as blue. The firmware now shows four labeled color bands for 3 seconds at boot to catch it.
