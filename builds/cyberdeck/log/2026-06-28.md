Started assembling the deck around an 8 GB Raspberry Pi 5, with a 7" touchscreen as the only display. Text comes from a Mii Bluetooth keyboard, pointing from an M5Stack Stick running a Joy-C, which is a stand-in mouse and a strange little one.

That's the whole input story. No external host, no Pi software yet: this half of the rig is hardware assembly.
