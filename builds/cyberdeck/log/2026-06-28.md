Started assembling the deck around an 8 GB Raspberry Pi 5 with a 7" touchscreen as the main display. Text input comes from a Mii Bluetooth keyboard; pointer input from an M5Stack Stick running a Joy-C, which stands in as the mouse. Together they make the deck a self-contained portable computer with no external host. No Pi software yet — this half of the rig is hardware assembly only.
