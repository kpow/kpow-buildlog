Spun off vizMini: the same face engine on an ESP32-C3 SuperMini and a 1-bit 128×64 OLED, which is about the cheapest hardware it will run on. Being drawn from primitives paid off here, since the face just renders smaller and in one colour.

The capacitive pad became a debounced pushbutton, the sleep state went away so it stays awake, and it takes OTA updates over the web.
