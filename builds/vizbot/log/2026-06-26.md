Spun off vizMini: a standalone, pared-down vizbot for an ESP32-C3 SuperMini driving a 1-bit 128×64 OLED — the same face engine on the cheapest hardware it would run on. Added an onboard NeoPixel rainbow glow, swapped the capacitive pad for a debounced pushbutton, dropped the sleep state so it stays awake, and added web OTA updates.
