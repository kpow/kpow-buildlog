Landed vizCloud integration with a static BSS framebuffer for zero-flicker TLS, an isolated cloud task on Core 0, and a unified WiFi task. Built Stage 4/5 multi-bot orchestration on top of it. Added an ESP-NOW local mesh doing cooperative WLED arbitration — flag bits in a broadcast packet so two bots won't drive the same matrix at once, with one deferring its speech bubble until a peer releases the display.
