The bots learned about each other.

vizCloud integration landed first: a static BSS framebuffer so TLS doesn't flicker the screen, an isolated cloud task on core 0, one unified WiFi task. Multi-bot orchestration went on top of that.

Locally they form an ESP-NOW mesh that arbitrates for the WLED matrix, using flag bits in a broadcast packet. Two bots won't drive the same matrix, and one will hold its speech bubble until a peer lets go of the display. Watching a bot wait its turn is the first time the fleet felt like a fleet.
