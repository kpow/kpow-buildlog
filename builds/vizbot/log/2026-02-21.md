Added an M5Stack Core S3 target with a multi-screen layout system: a layout.h that derives the UI from screen size, so a new display is a compile flag rather than a rewrite. Gave each bot its own identity — a unique per-device SSID and mDNS hostname derived from the eFuse MAC, plus a user-settable device name for a memorable hostname. Groundwork for running more than one bot at a time.
