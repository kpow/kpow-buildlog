Added an M5Stack Core S3 target, and with it a `layout.h` that derives the UI from the screen size. A new display is a compile flag now, not a rewrite.

Each bot also got an identity: a per-device SSID and mDNS hostname derived from the eFuse MAC, plus a name you can set yourself so it's memorable rather than hex. That's the groundwork for more than one of these existing at once.
