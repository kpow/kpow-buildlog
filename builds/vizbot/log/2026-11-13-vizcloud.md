VizCloud got rebuilt end to end. The fleet it runs is small: under 25 bots, gifts for close friends this Christmas. Recipients never log in, and a few friends edit content with full access.

- **Look:** a new design called Toybox, in vizBot black and yellow with Slackey headings. Bots show their real faces, drawn by a TypeScript port of the face model generated from the firmware headers.
- **Editors:** each has their own login, and every change lands in an activity log with who made it.
- **Publishing:** edits save right away but reach bots only on Publish, which stores an immutable release. Rollback points back at an earlier one. Each kind of bot gets only the content it can use, trimmed to its size budget, so publish never refuses for size.
- **Commands:** a persistent log, queued then delivered.
- **Bots:** new bots wait for approval, and each one's name comes from the bot itself. Online history shows when each was awake.
- **Firmware:** updates are uploaded and assigned to bots from the admin. vizMini is now a supported device.

Under it: one TypeScript Node service on Postgres, a React client, and a soak test of 50 simulated bots across all five hardware types on both protocols.
