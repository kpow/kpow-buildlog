vizbrain had only ever run on one Mac, from a git checkout, in this lab. Before giving it to a friend, five reviews went over it: install, assumptions about my house, security, what a first run looks like, and the docs.

What they found:

- **Anyone on the WiFi could spend my API key.** The server listened on every interface with no check, and any web page open on the Mac could post to it too.
- **It called everyone Kevin**, assumed Richmond for weather and search, and said "Lights on!" in a house with no lights.
- **The install failed at step one.** A stock Mac's Python is 3.9; vizbrain needs 3.11.
- **"Hey vizBot" only exists on my disk.** The model is trained on my voice, so friends get head-tap only.

1.1.0 fixes those. The typing page and log answer only on the Mac itself, and the bot's routes need a pairing token that the brain hands the bot (firmware 3.7.31). Spending stops at $2 a day or $20 a month, and he says so. His name for you comes from the Mac account, a setup step asks for your city, and tools for gear that isn't there aren't offered. A one-line installer brings its own Python, and `vizbrain doctor` checks everything and prints a report safe to paste to me.

Tested on the Stackchan: flashed 3.7.31, it paired, and the first sentence started 1.7 s after I stopped talking. Requests without the token were refused.
