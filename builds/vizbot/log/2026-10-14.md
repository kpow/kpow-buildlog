vizbrain is shared by invitation: each person gets an install link from me, and all the instructions are public. Before sending one, I ran the whole thing on my other Mac as a friend would.

It installed and Claude answered, but the bot never switched over. The background copy got "No route to host" on every call to him, while the same call from Terminal worked.

> **Trap:** macOS Local Network privacy blocks login agents, not Terminal. A bare Python agent gets filed under "Python", and on that Mac the switch was on and still didn't apply. vizbrain now installs a small vizbrain.app and points the agent at it, so macOS asks once for "vizbrain". The bot paired 40 s later.

The same test turned up two more:

- **Restart:** `vizbrain restart` left it stopped. The "already running?" check mistook the old copy's closing connections for a running copy.
- **Personal keys:** mine needs a workspace ID sent with every request. Setup now asks for it.

All three went out as 1.1.1. I wiped that Mac and installed from scratch following only the README, and the bot answered. Then a friend installed it herself, and it worked exactly as expected.
