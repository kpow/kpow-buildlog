Several days of networking, and one crash that ate most of them. The web server had moved to a FreeRTOS task on core 0, and core 0 kept going down with it. I went through watchdog reconfigures and stack-size bumps before the WiFi task would stay up.

The rest of the hardening, in the order it landed:

- a sequential boot loader with onscreen diagnostics, so a failure names itself
- an I2C mutex and a command queue, so two callers can't talk over each other
- WiFi provisioning with credentials in NVS
- a captive portal with DNS and mDNS auto-redirect
- persistent settings and a health heartbeat
