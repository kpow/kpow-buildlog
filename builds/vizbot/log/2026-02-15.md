Spent several days hardening the networking. Added a sequential boot loader with onscreen diagnostics, an I2C mutex and command queue for race safety, moved the web server to a FreeRTOS task on Core 0, added WiFi provisioning with NVS-stored credentials, and a captive portal with DNS + mDNS auto-redirect. The Core 0 crash took the longest — chased it through watchdog reconfigures and stack-size bumps before the WiFi task stayed up. Closed out with persistent settings and a health heartbeat.
