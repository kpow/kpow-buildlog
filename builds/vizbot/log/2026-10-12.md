The pendant has no use for WiFi, so the 1.69 got a low power mode. Hold Low power in System and the bot restarts into it:

- **Radio:** never started. No WiFi join, hotspot, web server, mesh or cloud.
- **CPU:** 80 MHz instead of 240.
- **Backlight:** 60% of the brightness setting.

Boot went from 8.2 s to 1.3 s. Current draw isn't measured yet. The pendant runs without the 5x5 LED panel. Shipped as v3.7.19.

> **Trap:** The boot log said "PSRAM: not found" while the canvas sat in PSRAM. The build used a no-PSRAM board definition, so the Arduino core compiled its PSRAM check to return false. That capped cloud replies at 16 KB. Registration is 42,702 bytes, so this 1.69 had never registered. One build flag fixed it in v3.7.20.
