v3.7.31 went out for all four boards: the 1.69 battery meter and touch fix, and the Stackchan pairing with vizbrain.

The 1.69 and 1.3 factory images carried a QIO flash header. A new 1.69 with a different flash chip boot-looped on one, because the ROM can't read that chip in QIO. The same file flashed in DIO mode booted fine.

PlatformIO builds the bootloader with a DIO header even for QIO boards; the bootloader switches modes itself. The build script was stamping QIO over it while merging the factory image. It now keeps the header as built. The two files on the release were replaced the same day; only the 33-byte bootloader header changed.
