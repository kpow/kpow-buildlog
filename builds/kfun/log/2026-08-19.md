A QMI8658C shake HAL: physically shaking the console restarts the current game. bigfun has no IMU, so it gets a no-op stub and the games don't care which one they're on.

The engine resumes from NVS too, so a game picks up where you left it. And the enclosure is packaged as a sliceable 3MF project now, one print from a shell.
