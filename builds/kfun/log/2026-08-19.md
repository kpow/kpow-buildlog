Wired up a QMI8658C shake HAL — a physical shake restarts the current game — with a
no-op stub on bigfun since it has no IMU, and made the engine resume games from NVS
so you pick up where you left off. Also packaged the enclosure as a sliceable 3MF
project so the shell is one print away.
