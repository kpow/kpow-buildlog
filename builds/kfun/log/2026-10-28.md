The v2 case leaves no easy way to the board's USB port, so updates have to go over the air. tinyFun had one 3 MB app slot and no room for a second. It moved to two 1.875 MB slots, leaving about 550 KB for the rest of the sprint. NVS stays put, so saved games survive.

The launcher got an Update card. It starts the board's own hotspot with a fresh 8-digit password on screen and serves an upload page: pick the .bin, press Upload. I chose a hotspot over home Wi-Fi so no credentials live on the device. A new image runs on probation and should roll back if it resets in the first 5 seconds. A browser upload worked on device. A deliberately bad image hasn't been tried yet.

Backgammon on tinyFun plays matches now: the flow follows match length instead of screen shape, Options picks 1/3/5/7 and remembers it, and a quit match offers CONTINUE or NEW.

> **Trap:** the partition switch needs one last USB flash, before the case closes.
