Touch was the day. Moved to pressure-based reads, threw out the four-corner min and max map for a projective calibration, and made the handheld run calibration on first boot instead of shipping my bring-up constants to every board.

LED rotation became a per-device setting in NVS too, because every matrix ends up mounted a different way in a different case, and a constant only ever describes the one on my desk.
