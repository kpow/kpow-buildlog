Whole spine in a day, both ends of it.

The web side: the icon format and its shared library, a C header export, a Postgres-backed API, the catalog, editor and palette pages, deployed onto DigitalOcean App Platform. Then the firmware scaffold, the CYD brought up, WiFi setup, and a first sync landing real icons in a LittleFS cache.

The panel fought back for an hour. Colours only come out right as BGR with inversion on, and the ILI9341 has no reset pin, so it keeps whatever inversion state it had across a warm reset and has to be told again at every boot.
