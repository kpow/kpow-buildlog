🔗 repo started 2026-03-23

A modular LED light instrument that turned into a distributed system. It started as one microcontroller driving a few panels — but when it ran out of pins, I gave every panel its own chip and linked them wirelessly. Now I can keep adding surfaces without ever hitting a hardware wall, and they all animate together in real time.

Project Info

An ESP32-S3 core (Adafruit FeatherS3) commands a fleet of ESP-NOW satellites — 8×8, 16×16, and 12×8 matrices, an RGBW bar, a mic satellite, a haptic dial remote, and a motorized disco ball — each its own ESP32-C3. The core broadcasts one 58-byte packet; every satellite receives the same packet and renders locally, staying frame-synced without the core pushing every pixel.

  • Dual-core FreeRTOS — radio on one core, FastLED render on the other, so they never step on each other (the S3’s RMT peripheral fights the WiFi radio if you get the startup order wrong).
  • 16 FastLED effects, audio-reactive via a 512-point FFT on the mic satellite that broadcasts bass/mid/treble/beat to the whole fleet.
  • Control surface: three NeoPixel encoders, a NeoSlider, a ToF proximity sensor, capacitive touch, PCA9685-driven LED filaments + skull, and a lightning-bolt lane.

Why it’s built this way

The distributed architecture wasn’t a flourish — it was running out of GPIO and refusing to stop adding panels. Moving each surface to its own wireless board means the system scales by adding boards, not pins.

2026-09-07

Landscape TFT + chrome refresh; the Patternflow bank

ui patterns

Recomposed the entire UI for a landscape 320×240 ST7789 mount — one-row header, framed menus, Live Control and Chladni re-laid-out. Landed the Patternflow bank too: hand-ported JS shader-style patterns running on all three boards, with the red Qwiic button as a palette dice.

2026-08-29

21 effects, a palette system, and ‘Noodle 2K’

effects palettes milestone

Big content wave: a trimmed 2D particle engine and the WLED particle effects (catalog to 21), a real 16-band GEQ spectrum analyzer, and a global palette system with host-parity tests and a dial palette picker. Rebranded the whole thing “Noodle 2K” with a new layered power-on intro. Also brought up a hub75 MatrixPortal satellite doing native 64×32.

2026-08-16

The big rebuild — bare MCU, Chladni, cyberpunk chrome

rebuild ui

Stripped the rig back to a bare MCU and brought it up clean: retired the icon and (later) 8×12 sats, drove the 16×16 locally, moved SparkFun inputs to their own I2C bus, and replaced the wireframe screensaver with a live Chladni-plate visualizer. Also redid the whole UI on an anti-aliased “chrome” kit and killed the flicker.

2026-06-13

Portability pass + matrix sat moves to an S3

firmware portability

Made the whole project portable to a new machine — pinned the pioarduino platform by URL across every board so builds are reproducible. Ported the 12×8 matrix satellite to a dual-core ESP32-S3 SuperMini for a better radio, and added a baked Pac-Chase animation source for the 16×16.

2026-05-27

Disco-ball satellite — and a nasty ground-noise lesson

satellites disco hardware-lesson

Added a motorized disco ball as its own satellite (stepper + spot LED + OLED) with a dedicated LiveTarget. First version ran the stepper off main power and it made the ground filthy — the noise bled into the rest of the Noodle. Its own supply fixed it. Classic motor-on-shared-ground trap.

2026-05-16

ESP-NOW only, plus a screen-capture path

esp-now streaming

Dropped WiFi association entirely — the Console runs pure ESP-NOW now. Started the screen-share path (browser → ingest → matrix) and a LittleFS clip store, so I can push real captured pixels to the 16×16, not just generated effects.
